# HIMS Backend Service (Express + TypeScript + Supabase)

Modular backend for the Hospital Information Management System (HIMS), integrating all 6 microservice domains into a clean, maintainable Express + TypeScript architecture backed by Supabase PostgreSQL.

---

## 🏗️ Architecture

```
Client (React / Next.js / Mobile)
               │ HTTP REST
               ▼
   Express.js Monolith API (:3000)
┌────────────────────────────────────────────────────────┐
│  /api/patients  ───► Patient Management                │
│  /api/opd       ───► OPD & Appointments & Queue        │
│  /api/clinical  ───► Clinical / EMR (Consultations)     │
│  /api/lims      ───► Laboratory Information System     │
│  /api/pharmacy  ───► Pharmacy & Stock & Dispensing     │
│  /api/finance   ───► Billing, Invoicing & Payments     │
└────────────────────────────────────────────────────────┘
               │
               ▼
   Supabase (PostgreSQL 15+)
   • 17 Tables + Indexes
   • Triggers (UHID generator, Department Queue tokens)
   • Atomic PL/pgSQL function (dispense_drugs)
   • SQL View (invoice_summary)
   • Supabase Storage (lab-reports bucket)
```

## 🚀 Quick Start

### 1. Prerequisites
- Node.js 18+ installed
- Supabase Project created with `00_migration.sql` executed (see [`supabase/`](../supabase/))

### 2. Install Dependencies
```bash
cd backend
npm install
```

### 3. Configure Environment
Edit `.env` with your Supabase credentials:
```env
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_ANON_KEY=eyJ...
SUPABASE_SERVICE_ROLE_KEY=eyJ...
PORT=3000
```

### 4. Run Development Server
```bash
npm run dev
```
The server will start with hot-reload at `http://localhost:3000`.

## 📡 Complete API Reference

### 1. Patient Management (`/api/patients`)
| Method | Endpoint | Description |
|---|---|---|
| `POST` | `/api/patients` | Register new patient (UHID auto-generated by DB) |
| `GET` | `/api/patients` | List patients with pagination & search (`?search=amit&page=1&limit=20`) |
| `GET` | `/api/patients/:id` | Get patient by UUID |
| `GET` | `/api/patients/uhid/:uhid` | Get patient by UHID (`HIMS-2026-00001`) |
| `PATCH` | `/api/patients/:id` | Update patient details |
| `DELETE` | `/api/patients/:id` | Soft-delete patient (`is_active = false`) |

### 2. OPD & Appointments (`/api/opd`)
| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/api/opd/departments` | List all active departments |
| `POST` | `/api/opd/departments` | Create hospital department |
| `GET` | `/api/opd/doctors` | List doctors (`?departmentId=...&available=true`) |
| `POST` | `/api/opd/doctors` | Create doctor linked to department and user |
| `GET` | `/api/opd/doctors/:id` | Get doctor details with department |
| `PATCH` | `/api/opd/doctors/:id` | Update doctor info / availability |
| `POST` | `/api/opd/appointments` | Book appointment (Token number auto-assigned by DB) |
| `GET` | `/api/opd/appointments` | List appointments (`?patientId=&doctorId=&deptId=&date=&status=`) |
| `GET` | `/api/opd/appointments/:id` | Get appointment details |
| `PATCH` | `/api/opd/appointments/:id/status` | Update status (`scheduled`, `checked_in`, `in_progress`, etc.) |
| `GET` | `/api/opd/appointments/queue/:deptId/:date` | Get patient queue for department on date |

### 3. Clinical / EMR Service (`/api/clinical`)
| Method | Endpoint | Description |
|---|---|---|
| `POST` | `/api/clinical` | Create consultation (supports embedded prescriptions & referrals) |
| `GET` | `/api/clinical` | List consultations (`?patientId=&doctorId=&status=`) |
| `GET` | `/api/clinical/:id` | Get full consultation with prescriptions & referrals |
| `GET` | `/api/clinical/appointment/:appointmentId` | Get 1:1 consultation for an appointment |
| `PATCH` | `/api/clinical/:id` | Update notes, diagnosis, ICD-10 codes, status |
| `POST` | `/api/clinical/:id/prescriptions` | Add prescription items to consultation |
| `PATCH` | `/api/clinical/prescriptions/:itemId/dispensed` | Mark prescription item as dispensed |
| `POST` | `/api/clinical/:id/referrals` | Add referral to consultation |

### 4. LIMS Service (`/api/lims`)
| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/api/lims/tests` | Get lab tests catalog |
| `POST` | `/api/lims/tests` | Add test to catalog |
| `POST` | `/api/lims/orders` | Create lab order with test items |
| `GET` | `/api/lims/orders` | List lab orders (`?patientId=&status=&priority=`) |
| `GET` | `/api/lims/orders/:id` | Get lab order with test results |
| `PATCH` | `/api/lims/orders/:id/status` | Update order status |
| `PATCH` | `/api/lims/orders/items/:itemId/result` | Update test item results & mark abnormal |
| `POST` | `/api/lims/orders/:id/report` | Attach report bucket path & mark delivered |
| `GET` | `/api/lims/orders/:id/report/download` | Generate 5-min signed URL from Supabase Storage |

### 5. Pharmacy Service (`/api/pharmacy`)
| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/api/pharmacy/drugs` | List drugs with computed current stock & low-stock indicator |
| `GET` | `/api/pharmacy/drugs/alerts/low-stock` | Get drugs below reorder level |
| `GET` | `/api/pharmacy/drugs/:id` | Get drug details with stock batches |
| `POST` | `/api/pharmacy/drugs` | Add new drug to formulary |
| `PATCH` | `/api/pharmacy/drugs/:id` | Update drug price / info |
| `POST` | `/api/pharmacy/stock` | Add stock batch with expiry date & quantity |
| `POST` | `/api/pharmacy/dispense` | **Atomic Dispense**: calls DB `dispense_drugs` RPC (FIFO expiry locks) |
| `GET` | `/api/pharmacy/dispense` | List dispense orders history |
| `GET` | `/api/pharmacy/dispense/:id` | Get dispense order details & items |

### 6. Finance Service (`/api/finance`)
| Method | Endpoint | Description |
|---|---|---|
| `POST` | `/api/finance` | Create invoice with optional initial line items |
| `GET` | `/api/finance` | List invoices (`?patientId=&status=`) |
| `GET` | `/api/finance/:id` | Get full invoice with line items, payments, and SQL summary |
| `GET` | `/api/finance/summary/patient/:patientId` | Get patient billing summary (from `invoice_summary` view) |
| `POST` | `/api/finance/:id/items` | Add line items (consultation, lab, pharmacy, procedure) |
| `POST` | `/api/finance/:id/payments` | Record payment & auto-update status (`partially_paid`/`paid`) |
| `PATCH` | `/api/finance/:id/issue` | Issue invoice & compute final total |
| `PATCH` | `/api/finance/:id/cancel` | Cancel invoice |
